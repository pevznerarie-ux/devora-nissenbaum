# Visual Intelligence Engine — chartes visuelles (style kits)

Un établissement, une matière ou une tranche d'âge peut définir une charte. À
défaut, quatre chartes par défaut (`DEFAULT_STYLE_KITS`) : 6–8, 9–11, 11–14,
15–18 ans.

## Objectif

Cohérence éditoriale et lisibilité, style **jamais excessivement enfantin**.

## À éviter (interdits communs)

esthétique IA générique · 3D plastique · personnages déformés · yeux trop grands
· fausse typographie · fonds surchargés · lumière artificielle excessive · style
publicitaire · images sans rapport pédagogique · caricatures non demandées.

## Champs

style éditorial, ambiance, trait, fond, style de personnage, niveau de réalisme,
palettes (autorisées/préférées/interdites), types autorisés/interdits,
`promptPrefix`/`promptSuffix`, instructions négatives, assets de référence.
